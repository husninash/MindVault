# MindVault

Live site: https://mindvaultforme.netlify.app/

Static HTML/JS app (no build step) backed by Supabase, hosted on Netlify.

## Database setup

Run `supabase_schema.sql` in the Supabase SQL Editor. It is safe to re-run on an existing database.
The comments at the bottom of that file show how to claim pre-existing rows for your account and how to grant the admin role.
